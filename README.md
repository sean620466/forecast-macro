# FORECAST MACRO

경제 데이터를 사람이 이해하기 쉽게 정리하고, AI가 현재 경제 상황을 분석하여 주요 거시경제 이벤트의 자체 확률을 계산하는 시스템입니다.

## Core goals

- Fed 금리 결정, CPI, 실업률, GDP, 경기침체 확률 추정
- 경제 데이터와 예측시장 가격 비교
- 자체 확률과 시장 가격의 차이가 충분히 클 때만 신호 표시
- ChatGPT와 Claude의 공동 검증 워크플로 구축

## Collaboration

- 설계, 코드, 가설은 저장소에서 관리합니다.
- 검증 결과는 `reviews/`에 기록합니다.
- 최종 의사결정은 `DECISIONS.md`에 남깁니다.
