# Backtest and Calibration Plan

## 목적

baseline 확률이 단순히 방향을 맞히는지를 넘어, 장기간 실제 빈도와 일치하는지 평가한다.

## 시간 기준

- 모든 feature는 예측 생성시각 이전에 공개된 값만 사용한다.
- 관측월이 아니라 실제 발표시각을 기준으로 입력을 제한한다.
- 가능한 경우 ALFRED/FRED vintage를 사용해 당시 공개값을 재구성한다.
- revised 최신값만 이용한 성과는 공식 백테스트로 인정하지 않는다.

## 검증 방식

1. 초기 최소 학습구간을 정한다.
2. 시간순 expanding-window 방식으로 다음 회의를 하나씩 예측한다.
3. 각 예측은 모델 버전, 입력 vintage, 생성시각과 함께 저장한다.
4. Brier score, log loss, calibration table, ECE를 산출한다.
5. 단순 baseline과 예측시장 종가 확률을 동일 조건으로 비교한다.

## 합격 기준 초안

- 미래정보 누출 0건
- 모든 확률은 0~1이며 결과군 합계는 1
- 무조건 다수결 baseline보다 낮은 Brier score
- 표본외 구간에서 성능 보고
- 최소 표본 수에 도달하기 전에는 사용자에게 모델 우위를 주장하지 않음

## 아직 필요한 데이터

- FOMC 회의별 결정 및 결정시각
- 각 회의 직전 사용 가능했던 CPI/PCE/고용/금리 vintage
- 예측시장 계약별 규칙, 거래 가격, 수수료, 마감시각
