# Prediction Market Contract Schema

## 목적

서로 다른 플랫폼의 계약을 모델 결과와 비교하기 전에 동일한 결과공간과 시점으로 정규화한다.

## Fed 기본 결과공간

- `hike`
- `hold`
- `cut_25`
- `cut_50_plus`

플랫폼 계약 정의가 다르면 강제로 합치지 않고 별도 mapping을 기록한다.

## 필수 필드

- 플랫폼 및 contract ID
- 회의/결과 결정시각
- 시장가격 관측시각
- 계약 원문과 해석 버전
- 상호배타적 outcome 목록
- 각 outcome의 bid/ask 또는 체결가
- 수수료 규칙

## 가격 처리

상호배타적 결과 가격의 합이 1에서 소폭 벗어나면 합계로 나눠 단순 overround를 제거한다. 합계가 허용범위를 크게 벗어나면 불완전하거나 서로 다른 계약으로 보고 거부한다. 플랫폼별 거래수수료는 이후 별도 비용 모델에서 edge와 비교한다.
